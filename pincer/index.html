The problem

Too many agents. Too many tabs.

Checking local agents means hopping terminals, dashboards, and browser tabs. Status goes stale before you finish the loop.

Context-switch tax

Each agent lives in its own terminal or UI. Hunting who is up, slow, or down costs minutes and focus every time.

Tray-first Pincer

One glance from the system tray. Live status, history, and charts stay beside your work.

Features

Ops for agents that run on your machine

Status, trends, incidents, and reports, stored locally and ready at a glance.

Tray-first live status

Check agent health from the menu bar or system tray in one glance.

Dashboards & trends

Charts and history show how agents behave over time, beyond the latest ping.

Incidents & heatmap

Catch failures as they land. Review incident history and heatmaps when an agent goes quiet.

Reports + HTML export

Generate reports to share or archive. Export HTML for a snapshot outside the app.

Flexible controls

Tune polling, retention, notifications, launch-at-login, and auto-update to match your setup.

Local-first, cross-platform

Data lives in local SQLite on macOS, Windows, and Linux. Agent payloads stay on your machine.

Agents

Works with the agents you already run

Built-in support, plus custom HTTP health endpoints for anything else you host locally.

How it works

Install. Add agents. Watch the tray.

Three steps from download to live tray status.

1

Install Pincer

Install with Homebrew, or download a build for macOS, Windows, or Linux.

2

Add your agents

Point Pincer at OpenClaw, Hermes, OpenCode, OpenCrabs, or any custom HTTP health endpoint.

3

Watch the tray

Live status stays in the tray. Optional pincerd keeps collecting after you close the desktop app.

Product

See it in action

Tray dashboard, agents, incidents, reports, and light mode.

Tray dashboard with live agent status

Keep collecting with pincerd

Run the optional daemon after you close the desktop UI. It runs on macOS arm64 and Linux x86_64. You host it and control the secret.

Daemon docs on GitHub

Install Pincer

Use Homebrew on macOS, or download the latest build for your platform from GitHub Releases.

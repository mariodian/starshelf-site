Privacy Policy

Effective date: August 4, 2026 · Last updated: August 4, 2026

This Privacy Policy explains how Starshelf (“Starshelf,” “we,” “us,” or “our”) handles information when you use the Starshelf browser extension for Chrome and Firefox (the “Extension”) and this website (the “Site”). Sensitive credentials stay on your device; we do not collect them.

1. Who we are

Starshelf is an open-source browser extension. It auto-categorizes GitHub starred repositories with AI providers that you configure.

Contact: starshelf.wistful980@slmail.me

2. Summary

  • Starshelf runs no backend that receives your API keys or GitHub token.
  • Keys and tokens live in your browser’s extension storage.
  • The Extension calls GitHub and your AI provider from your browser.
  • This Site is static. It uses no analytics cookies or ad trackers.

3. Information the Extension handles

3.1 Credentials you provide

On your device, local extension storage may hold:

  • A GitHub personal access token (or equivalent) that you supply
  • An API key for your AI provider (Anthropic, OpenAI, or OpenCode)
  • Provider, model, formatting, and related settings

The Extension uses these values only to call those services on your behalf. We neither receive nor store copies. Starshelf provides no servers for that purpose.

3.2 Categorization and repository data

To categorize repositories, the Extension may:

  • Read repo metadata (for example name, description, and language) from the GitHub API or github.com
  • Send that information to your AI provider to obtain a category label
  • Create or update GitHub lists on your account per your settings
  • Cache results and related state in browser storage (including session storage for batch progress)

3.3 Permissions

The Extension requests limited permissions:

  • storage — keep settings and categorizations on your device
  • github.com and api.github.com — content scripts, star detection, and list or API work
  • AI provider hosts you use (for example Anthropic, OpenAI, OpenCode) — categorization with your key

4. Third-party services

When you use the Extension, your browser talks directly to third parties you choose or that GitHub requires:

  • GitHub — authentication, repository data, and lists, under GitHub’s privacy policy and terms
  • AI providers (Anthropic, OpenAI, OpenCode, or others you configure) — prompts and metadata for categories, under each provider’s policies. You must follow those terms for data you send with your key
  • Browser vendors (Google, Mozilla, and others) — store distribution and updates under their policies

Once data leaves your browser under your credentials, those parties control how they process it.

5. This website

The Site is static (for example on GitHub Pages). It offers product information, this Privacy Policy, and Terms of Service.

  • We collect no personal information through forms on this Site.
  • We use no third-party analytics, ad pixels, or tracking cookies.
  • Hosts (GitHub Pages, CDN, or DNS) may log IP address, user agent, and request URL. The host controls that logging; Starshelf has no application backend for it.

6. Children’s privacy

Starshelf is not directed to children under 13 (or the minimum age where you live). We do not knowingly collect personal information from children.

7. Data retention and deletion

Credentials and categorizations live in your browser’s extension storage, so you control retention. You may:

  • Clear or change keys and settings in the Extension popup
  • Remove the Extension (browsers usually delete its local storage)
  • Revoke GitHub tokens and AI API keys in those providers’ dashboards

Starshelf keeps no separate user-account database for the Extension.

8. Security

Starshelf keeps secrets local and uses them only for the APIs you configure. No storage or transmission is perfectly secure. Protect your device, browser profile, and API keys, and use GitHub tokens with limited scopes.

9. International users

GitHub and your AI provider may process data in several countries under their rules. The host may serve this Site from more than one region.

10. Your choices and rights

Your jurisdiction may grant rights over personal data (access, deletion, correction, and more). For data only on your device, use the Extension and browser controls above. For data held by GitHub or an AI provider, contact them.

Privacy questions about Starshelf: starshelf.wistful980@slmail.me.

11. Open source

Extension source code is at github.com/mariodian/starshelf. You can review how storage and network calls work.

12. Changes to this policy

We may update this Privacy Policy. The “Last updated” date at the top will change when we do. If you keep using the Extension or Site after a change, you accept the revised policy where the law allows.

13. Contact

Privacy inquiries: starshelf.wistful980@slmail.me
Issues and security reports: GitHub Issues

This policy supports transparency and store compliance. It is not legal advice. For advice about your situation, consult a qualified attorney.
